Jira Kanban Reports: Cumulative Flow, Control Chart, Throughput

Interactive mockup of key Kanban reports using sample data for Devendrappa's support/maintenance Kanban board (Bengaluru team, as of Feb 12, 2026). Focuses on flow health: bottlenecks, cycle time stability, throughput trends. Change metrics or time window to update charts dynamically.

Cumulative Flow Diagram (CFD)
Cumulative Flow – Work Items by Status Over Time

Area chart showing arrivals, WIP and departures. Widening bands = bottlenecks. Ideal: roughly parallel bands with stable WIP.

Control Chart – Cycle Time
Cycle Time Scatter + Averages

Each dot = one completed issue. Orange dots show actual cycle times. Green dashed line ≈ average. Helps spot predictability & outliers.

Throughput (Velocity) Trend
Completed Items per Week

Weekly throughput (green bars) + 4-week rolling average (blue line). Useful for forecasting and spotting delivery stability.

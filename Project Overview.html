“Project overview” dashboard

Agile metrics showing productivity across the software development lifecycle. Sample data for 3 projects (as of Feb 11, 2026). Interactive demo — change filters to update charts dynamically.

Key Metrics
Net Flow of Work (weekly)

Difference: completed committed items minus newly committed items per week.
Positive = focus on existing work; Negative = new scope added.

Defect Ratio (% defects of completed work)

% of Bugs/Defects out of total completed items per week/project.
Lower trend = improving quality. Changes with Defect Type.

Throughput (completed items per week)

Number of work items completed each week, grouped by project.

Responsiveness (avg cycle time in days)

Average days from "In Progress" to "Done" for items completed that week.
